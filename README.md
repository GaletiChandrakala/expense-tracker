# Expense Tracker

A simple Python command-line application for managing daily expenses.

## Project Overview

The Expense Tracker helps users record, view, search, and calculate their expenses.

## Features

- Add Expense
- View Expenses
- Calculate Total Expenses
- Search Expense by Category
- Exit the application

## Technologies Used

- Python 3
- Lists
- Dictionaries
- Loops
- Conditional Statements
- User Input

## How the Project Works

1. The program displays a menu.
2. The user selects an option.
3. For adding an expense, the user enters category, description, and amount.
4. The expense is stored in a list as a dictionary.
5. The user can view all expenses.
6. The program can calculate the total amount.
7. The user can search expenses by category.
8. The user can exit the program.

## Example

Food → Lunch → ₹150

Transport → Bus → ₹50

Shopping → Shirt → ₹800

Total Expense → ₹1000

## Purpose of the Project

This project was developed to practice Python programming concepts and solve a simple real-world expense management problem.
